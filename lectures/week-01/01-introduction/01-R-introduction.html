Introduction to R & Environmental Data

Today we will use a real environmental monitoring dataset to begin answering a simple question:

What happened to ambient particle concentrations during five days of winter monitoring?

We will use R to:

  • obtain the data;
  • inspect the data;
  • check the measurements;
  • calculate simple summaries;
  • create a visualization;
  • interpret what we see.

Start With the Question

We have measurements

Imagine that an instrument collected repeated measurements of airborne particles over several days.

The measurements change through time.

Some are relatively low.

Some are higher.

Some periods appear more variable than others.

Note

Our first task is not to write code.

Our first task is to ask:

What can these measurements tell us?

The Monitoring Problem

Winter ambient particle monitoring

The dataset comes from local ambient particle monitoring conducted during:

December 27–31, 2019

Measurements were collected approximately every:

2 minutes

The monitoring period occurred during winter, when local conditions could include particle emissions associated with activities such as residential heating and wood burning.

What Was Measured?

Particle concentration

The monitoring instrument recorded repeated measurements of:

airborne particle concentration

Our dataset contains two variables:

Variable Meaning
date_time When the measurement was collected
concentration Measured particle concentration

An Important Scientific Distinction

Measurement ≠ Source Attribution

The instrument measured particle concentration.

It did not identify the source of every particle.

Therefore, a high measurement does not automatically tell us:

  • what produced the particles;
  • where they came from;
  • whether one particular source was responsible.

Important

Observation is not the same thing as explanation.

Why R?

Data are evidence

Environmental and hazardous-material decisions increasingly depend on data.

We may collect:

  • air measurements;
  • water measurements;
  • soil measurements;
  • surface samples;
  • direct-reading instrument data;
  • meteorological data;
  • exposure measurements.

The measurements themselves are only the beginning.

We still need a way to:

organize → inspect → analyze → visualize → communicate

What Is R?

R

R is a programming language and analytical environment used for:

  • working with data;
  • statistical analysis;
  • visualization;
  • reproducible research.

R allows us to give the computer instructions and preserve those instructions so we can see exactly how an analysis was performed.

What Is RStudio?

RStudio is our workspace

RStudio provides an interface for working with R.

You will commonly see four areas:

Source

Where we write and save code.

Console

Where R executes commands.

Environment

Shows objects currently available in R.

Files / Plots / Packages / Help

Tools for navigating files, viewing graphs, managing packages, and getting help.

One Important Habit

Save your work in a script

You can type commands directly into the Console.

But commands entered only into the Console are easy to lose.

Instead, we will generally write commands in a script.

Tip

The script is our record of what we did.

That becomes important for reproducibility.
